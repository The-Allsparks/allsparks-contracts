# [phase] Document third-party use outside Allsparks projects

## Problem

Other FTC teams may want the JAR without the rest of the Allsparks stack. The README says that is allowed; install and support boundaries are still thin.

## Student learning objective

A visiting team can copy one example capability provider without installing TRACE or HELM.

## Scope

A short third-party guide: coordinates, Java 11, no FTC dependency, how to map local enums, where to file issues.

## Out of scope

Support for Android-specific packaging. Shipping season game-piece types.

## Acceptance criteria

- [x] Guide linked from README
- [x] Example still compiles with only this JAR

## Hardware validation required

- [x] None
