# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a vulnerability

Please do **not** open a public issue for security problems that could put robots, students, or machines at risk.

**Private channel (preferred):** use [GitHub Private Vulnerability Reporting](https://github.com/The-Allsparks/allsparks-contracts/security/advisories/new) for this repository. Maintainers receive the report privately and can coordinate a fix before any public disclosure.

This library does not command hardware. Still treat unexpected authority, hidden threads, or a path that would let a consumer believe `UNKNOWN` is ready as a safety defect.

Include:

- A description of the issue
- Steps to reproduce
- Impact assessment

## Secrets

Never store passwords, Wi-Fi credentials, API keys, or tokens in the repository, issues, or exported logs.
